Privacy policy

This policy describes the personal Strateole2-Rclone workflow's use of Google account data. Last updated: November 11, 2026.

What Google user data is accessed

When authorized by the operator through Google OAuth, Rclone can access Google Drive file listings, metadata, and file contents allowed by the granted permission scope. The workflow uses this access to read designated daily CSV data and to upload processed NetCDF files to designated Drive folders.

How data is used

Data is used solely to perform the operator's configured research file-transfer and processing tasks. Files are downloaded to a user-managed computing environment, processed using local Python scripts, and the results uploaded to the selected Google Drive destination. A separate FTP server supplies a reference data file; the workflow does not upload Google Drive data to that FTP server.

Storage and retention

Google Drive file copies and derived scientific outputs may be stored on the operator's Linux computer and within the Google Drive folders chosen by the operator until the operator removes them. Rclone stores OAuth configuration and access tokens in a local user-controlled configuration file. This informational website does not store Google Drive content or OAuth tokens.

Sharing

This personal workflow is not designed to sell, advertise with, or distribute Google user data to third parties. Processed output is sent to the Google Drive destination configured by the operator, where normal Google Drive sharing permissions apply. The operator is responsible for choosing and managing those permissions.

Security and control

Access is authorized through Google's OAuth flow and managed by Rclone. Only the operator should have access to the local configuration and output directories. Google account authorization can be reviewed or revoked in Google Account third-party connections. Revoking access will prevent further Drive transfers until reauthorized.

Website data

These static pages do not include sign-in forms, analytics scripts, or advertising trackers. The GitHub Pages hosting provider may process technical request information under its own privacy practices.

Contact and updates

For questions or requests about this personal integration, contact the developer using the support email listed on the Google OAuth consent screen. This policy will be revised if the workflow's Google user-data practices change.

This policy describes the intended configuration. The operator should confirm that it accurately reflects their actual Rclone remotes, storage, access permissions, and data-handling practices before publishing.
