PERSONAL RESEARCH WORKFLOW

Scientific data transfers with Google Drive and Rclone

Strateole2-Rclone is a personally operated workflow for downloading authorized scientific CSV files from Google Drive, processing them on a user-managed Linux computer, and uploading resulting NetCDF files to a selected Google Drive destination.

What it does

  1. Uses Rclone and Google OAuth authorization to access Google Drive files and folders selected by the operator.
  2. Downloads daily scientific CSV records; separately retrieves a reference NetCDF file from a configured FTP server.
  3. Runs local Python data processing, including time matching, interpolation, and NetCDF creation.
  4. Uploads processed NetCDF output to a Google Drive location chosen by the operator.

How Google data is used

Google Drive access is used only to list, download, and upload files required for the configured workflow. The workflow is intended for the operator's own authorized scientific data and is not a public Google Drive service.

Google OAuth credentials are managed by Rclone on the operator's computer; this public informational website does not request Google sign-in or collect authentication tokens.

This site describes a personal workflow that uses the open-source Rclone tool. It is not affiliated with or endorsed by Google or the Rclone project.
